# FXT 固定时间编队控制 — 调参方案

> 日期：2026-10-16
> 前提：三阶段代码已落地，FXT 控制律在上位机 20Hz 运行，方案A（上位机积分）

---

## 1. 调参挑战

| 因素 | MATLAB 仿真 | 实验平台 | 影响 |
|------|------------|---------|------|
| 控制频率 | 1000 Hz | 20 Hz | 积分步长 ×50，离散误差增大 |
| 系统模型 | 理想二阶积分 | 真实底盘+通信延迟 | 未建模动态 |
| 状态测量 | 无噪声 | 传感器噪声+UDP延迟 | ω 抖动 |
| 参考轨迹 | 正弦（光滑） | 矩形（分段，顶点不可导） | 顶点处冲击 |

**核心风险**：MATLAB 增益（k_p1=4.5 等）在 1000Hz 下整定，直接用于 20Hz 可能振荡或发散。

---

## 2. 参数说明

### 2.1 控制律参数

```
u = ref_acc - k_p1·sign(e_pos)^α_p - k_p2·sign(e_pos)^β_p
          - k_v1·sign(e_vel)^α_v - k_v2·sign(e_vel)^β_v
```

| 参数 | 作用 | 范围 | MATLAB值 |
|------|------|------|---------|
| α_p | 位置非线性幂次（小误差主导） | (0, 1) | 0.5 |
| β_p | 位置非线性幂次（大误差主导） | (1, ∞) | 1.5 |
| k_p1 | 位置非线性增益（小误差收敛速度） | > 0 | 4.5 |
| k_p2 | 位置线性增益（大误差收敛速度） | > 0 | 2.0 |
| k_v1 | 速度非线性增益 | > 0 | 3.2 |
| k_v2 | 速度线性增益 | > 0 | 1.4 |
| α_v | 速度非线性幂次 | = 2α_p/(1+α_p) | 0.667 |
| β_v | 速度线性幂次 | = 2β_p/(1+β_p) | 1.2 |

### 2.2 运行参数

| 参数 | 作用 | 范围 | 默认 |
|------|------|------|------|
| speed | 参考速度 | 0.05~0.7 m/s | 0.2 |
| formation_type | 队形 | diamond/triangle/line | diamond |

## 3. 初始参数估算

### 3.1 频率缩放法

MATLAB 增益在 1000Hz 整定，平台 20Hz。离散积分 `v += u·dt`，dt 从 0.001→0.05。

**保守估计**：增益按频率比缩放（÷50），但太小会收敛极慢，不实用。

**实用估计**：按 √(频率比) 缩放（÷7），平衡收敛速度与稳定性：

| 参数 | MATLAB | ÷50（太保守） | ÷7（推荐起点） | 不缩放（激进） |
|------|--------|--------------|---------------|--------------|
| k_p1 | 4.5 | 0.09 | **0.64** | 4.5 |
| k_p2 | 2.0 | 0.04 | **0.29** | 2.0 |
| k_v1 | 3.2 | 0.064 | **0.46** | 3.2 |
| k_v2 | 1.4 | 0.028 | **0.20** | 1.4 |

### 3.2 三组推荐参数

| 组别 | k_p1 | k_p2 | k_v1 | k_v2 | 适用场景 |
|------|------|------|------|------|---------|
| **保守组** | 0.3 | 0.2 | 0.3 | 0.15 | 首次上电，验证不发散 |
| **推荐组** | 0.64 | 0.29 | 0.46 | 0.20 | 正常使用（÷7 缩放） |
| **激进组** | 1.5 | 0.8 | 1.0 | 0.5 | 追求快速收敛，需验证稳定性 |

> α_p=0.5, β_p=1.5 保持不变（幂次由理论决定，不随频率变）

## 4. 调参步骤

### 阶段一：领航者单车（空载）

#### 步骤 1：保守组验证

```
参数：保守组，speed=0.1
目标：不发散，能粗略跟踪矩形
观察：CSV 中 x,y 轨迹是否大致沿矩形
```

**操作**：
1. 前端设置保守组参数，速度 0.1 m/s
2. 启动 FXT 实验，运行 1 圈矩形
3. 停止下载 CSV
4. 绘制轨迹图，检查是否发散

**通过标准**：轨迹大致沿矩形，无发散，无剧烈振荡

#### 步骤 2：调位置环 k_p1, k_p2

```
固定：k_v1=0.3, k_v2=0.15, speed=0.1
调整：k_p1, k_p2
目标：位置误差快速收敛
```

| 轮次 | k_p1 | k_p2 | 观察 |
|------|------|------|------|
| 1 | 0.3 | 0.2 | 基准 |
| 2 | 0.5 | 0.3 | 收敛加快？ |
| 3 | 0.8 | 0.4 | 继续加快？ |
| 4 | 1.2 | 0.6 | 是否振荡？ |

**判断**：
- 收敛慢 → 增大 k_p1（小误差）或 k_p2（大误差）
- 振荡 → 减小 k_p1
- 超调大 → 减小 k_p2（β项主导大误差段）

#### 步骤 3：调速度环 k_v1, k_v2

```
固定：k_p1, k_p2 用步骤2最优值，speed=0.1
调整：k_v1, k_v2
目标：速度跟踪误差小，无振荡
```

| 轮次 | k_v1 | k_v2 | 观察 |
|------|------|------|------|
| 1 | 0.3 | 0.15 | 基准 |
| 2 | 0.5 | 0.25 | 速度跟踪改善？ |
| 3 | 0.8 | 0.4 | 继续改善？ |
| 4 | 1.2 | 0.6 | 是否振荡？ |

**判断**：
- 速度滞后 → 增大 k_v
- 速度振荡 → 减小 k_v1（非线性项敏感）
- 稳态速度误差 → 增大 k_v2

#### 步骤 4：提速测试

```
固定：步骤2-3最优增益
调整：speed = 0.1 → 0.15 → 0.2 → 0.3
目标：高速下稳定
```

**判断**：
- 高速振荡 → 回退增益或降低速度
- 高速稳定 → 确定工作速度

### 阶段二：跟随者编队

#### 步骤 5：跟随者调参

```
领航者：用阶段一最优参数
跟随者：从保守组开始
目标：编队保持，跟随者误差收敛
```

1. 领航者+1个跟随者，diamond 队形
2. 观察跟随者是否保持相对位置
3. 逐步增大跟随者增益（同步骤2-3方法）
4. 增加到 2~3 个跟随者

**判断**：
- 跟随者落后 → 增大 k_p
- 跟随者振荡 → 减小 k_v1
- 编队散开 → 检查槽位分配

### 阶段三：综合验证

#### 步骤 6：多圈稳定性

```
参数：阶段二最优
运行：连续 3~5 圈矩形
目标：长期稳定，无累积漂移
```

#### 步骤 7：抗扰测试

```
运行中手动推动一个车
目标：扰动后能恢复编队
```

## 5. 评估方法

### 5.1 CSV 数据分析

每次实验生成 `fxt_traj_{car_id}_{时间戳}.csv`，字段：
```
timestamp, car_id, x, y, yaw, vx, vy, set_vx, set_vy
```

**关键指标计算**（Python 脚本）：

```python
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv('fxt_traj_CAR1_xxx.csv')

# 1. 轨迹图
plt.plot(df['x'], df['y'])
plt.plot(df['set_vx'], df['set_vy'])  # 指令速度

# 2. 速度跟踪误差
df['vel_err'] = ((df['vx']-df['set_vx'])**2 + (df['vy']-df['set_vy'])**2)**0.5
plt.plot(df['timestamp'], df['vel_err'])

# 3. 位置误差（需与矩形顶点对比）
# 4. 收敛时间：误差首次降到 0.05m 以内的时刻
```

### 5.2 通过标准

| 指标 | 标准 |
|------|------|
| 位置误差稳态 | < 0.10 m |
| 速度跟踪误差 | < 0.05 m/s |
| 超调量 | < 0.15 m |
| 无振荡 | 速度不连续抖动 > 0.3 m/s |
| 收敛时间 | 1圈内收敛 (< 30s) |
| 多圈稳定性 | 3圈无漂移 |

## 6. 故障排查指南

| 现象 | 可能原因 | 处理 |
|------|---------|------|
| **发散（车跑飞）** | 增益过大 | 立即停止；k_p1,k_p2 减半重试 |
| **高频振荡** | 速度环增益过大 | 减小 k_v1；检查 ω 是否抖动 |
| **收敛极慢** | 增益过小 | 增大 k_p1（先）再 k_p2 |
| **稳态有偏** | 速度环太弱 | 增大 k_v2 |
| **顶点处冲过头** | 参考速度不减速 | 降低 speed；或顶点前减速 |
| **跟随者落后** | 前馈不足 | 增大跟随者 k_p1 |
| **跟随者振荡** | 跟随者速度环太强 | 减小跟随者 k_v1 |
| **积分饱和** | 速度限幅0.7频繁触发 | 降低 speed 或减小增益 |
| **ω 抖动大** | vz 传感器噪声 | 检查 car.omega 是否合理；可加低通滤波 |

## 8. 注意事项

1. **安全第一**：首次测试人在车旁，准备急停
2. **从低速开始**：0.1 m/s，确认稳定后再提速
3. **一次只调一个参数**：避免混淆因果
4. **先单车后编队**：领航者调好再加跟随者
5. **CSV 必存**：每次实验都下载分析
6. **增益上限**：k_p1 > 3.0 或 k_v1 > 2.0 时需特别谨慎
7. **速度限幅**：FXT_MAX_SPEED=0.7 是硬限幅，频繁触发说明增益过大
8. **ω 检查**：首次运行时打印 car.omega 确认传感器值合理（非0、非异常跳变）
