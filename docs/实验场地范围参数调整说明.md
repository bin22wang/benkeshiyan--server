## 2. 约束公式

```
设场地宽度 = FW，场地高度 = FH

矩形轨迹宽度  W = x2 - x1
矩形轨迹高度  H = y3 - y2
编队最大偏移  D = max(|slot_x|, |slot_y|)  （取所有队形中最大值）

约束：
  W + 2×D ≤ FW    （横向不越界）
  H + 2×D ≤ FH    （纵向不越界）
  留余量 ≥ 0.2m   （边界安全距离）
```

**整体占用空间**：(W + 2×D) × (H + 2×D)

## 3. RECT_POINTS 设置方法

矩形4个顶点，逆时针排列，每个顶点含 `x, y, yaw`：

```python
RECT_POINTS = [
    {"x": x1, "y": y1, "yaw": 0.0},      # 左下，朝右
    {"x": x2, "y": y1, "yaw": 90.0},     # 右下，朝上
    {"x": x2, "y": y2, "yaw": 180.0},    # 右上，朝左
    {"x": x1, "y": y2, "yaw": -90.0}     # 左上，朝下
]
```

- `x1, y1`：矩形左下角坐标
- `x2, y2`：矩形右上角坐标
- `yaw`：到达该顶点后期望航向（逆时针：0→90→180→-90）

**居中放置**（场地原点在左下角）：
```
x1 = (FW - W) / 2
y1 = (FH - H) / 2
x2 = x1 + W
y2 = y1 + H
```

## 4. FXT_FORMATION_SLOTS 设置方法

三种队形的槽位偏移 `[offset_x, offset_y]`（全局坐标系，单位 m）：

```python
FXT_FORMATION_SLOTS = {
    "diamond":   [[d, 0], [d, d], [0, d]],              # 菱形，边长 d
    "triangle":  [[d, 0], [-d/2, d*0.866], [-d/2, -d*0.866]],  # 等边三角形，边长 d
    "line":      [[d/2, 0], [-d/2, 0], [d, 0]]          # 直线，间距 d/2
}
```

- `d`：编队间距（跟随者之间或与领航者的距离）
- 偏移越小，编队越紧凑

## 5. 快速调整步骤

### 第1步：确定场地尺寸

```
FW = 场地宽度（m）
FH = 场地高度（m）
```

### 第2步：确定编队间距 d

```
d = min(FW, FH) × 0.15    （经验值：场地短边的15%）
```

### 第3步：计算矩形尺寸

```
W = FW - 2×d - 0.4    （减去编队展开和余量）
H = FH - 2×d - 0.4
```

### 第4步：计算顶点坐标（居中）

```
x1 = (FW - W) / 2
y1 = (FH - H) / 2
x2 = x1 + W
y2 = y1 + H
```

### 第5步：写入文件

修改 `Server_Web_UDP_26_7_14/formation_controller.py`：

- **第19-24行** `RECT_POINTS`：替换为新的4个顶点坐标
- **第63-67行** `FXT_FORMATION_SLOTS`：替换为新的槽位偏移

```python
# formation_controller.py 第19-24行
RECT_POINTS = [
    {"x": x1, "y": y1, "yaw": 0.0},
    {"x": x2, "y": y1, "yaw": 90.0},
    {"x": x2, "y": y2, "yaw": 180.0},
    {"x": x1, "y": y2, "yaw": -90.0}
]

# formation_controller.py 第63-67行
FXT_FORMATION_SLOTS = {
    "diamond":   [[d, 0.0], [d, d], [0.0, d]],
    "triangle":  [[d, 0.0], [-d/2, d*0.866], [-d/2, -d*0.866]],
    "line":      [[d/2, 0.0], [-d/2, 0.0], [d, 0.0]]
}
```

## 7. 验证方法

修改后用 Python 快速验证整体占用：

```python
# 修改后运行
FW, FH = 3, 3  # 替换为你的场地尺寸
x1, y1 = 0.75, 0.75
x2, y2 = 2.25, 2.25
W, H = x2 - x1, y2 - y1
D = 0.4  # 编队最大偏移
print(f"矩形: {W}×{H}m")
print(f"整体占用: {W+2*D}×{H+2*D}m")
print(f"场地: {FW}×{FH}m")
print(f"横向余量: {FW-W-2*D:.2f}m", "✅" if W+2*D <= FW else "❌")
print(f"纵向余量: {FH-H-2*D:.2f}m", "✅" if H+2*D <= FH else "❌")
```

## 8. 注意事项

1. **坐标系原点**：假设场地左下角为原点 (0,0)，x 向右 y 向上
2. **余量**：至少留 0.2m 边界安全距离，防止小车冲出场地
3. **小车数量**：槽位数 ≥ 跟随者数，否则多余跟随者无槽位
4. **速度适配**：小场地用低速（0.1~0.15 m/s），大场地可提速
5. **修改后验证**：运行第7节验证脚本，确认不越界
6. **CSV 检查**：首次运行后检查轨迹 CSV 的 x,y 范围是否在场地内
